# PlotterDash

Flask Web UI for controlling and printing from Penplotters

<img width="819" height="652" alt="Screenshot 2026-01-05 at 21 43 36" src="https://github.com/user-attachments/assets/c051565d-22cc-4514-bb3b-9a3f60d81c44" />


Allows for connecting to penplotter via serial connection, uploading SVG files, selecting pen and speed to be used.

Handles queing multiple files to be run one after another and convertion and optimisation of svg to hpgl code.
